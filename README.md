# Stroomprijs

Dutch dynamic energy price tracker: https://cerberostech.github.io/stroomprijs/

- Data: EnergyZero public API (api.energyzero.nl, no key), EPEX Spot day-ahead / ENTSO-E. Power `usageType=1`, gas `usageType=3`, `interval=4` (hourly), excl. VAT.
- `node build.mjs` fetches prices (falls back to `data/prices.json`) and writes the static site to `dist/`.
- `.github/workflows/pages.yml` rebuilds and deploys hourly (cron `7 * * * *`), IndexNow ping on push/manual.
- Price components (hero with the A–G price-class ladder, planner, chart, hour list, stats, gas) live in `lib/render.mjs`. `makeRender()` is self-contained: the build calls it for the first paint and the no-JS fallback, and inlines its source into the page so the browser re-renders with the real current hour (Europe/Amsterdam), the chosen price mode and the planner input. Client glue: `lib/app.js`. CSS: `lib/style.mjs`.
- "Schatting all-in" = (market price + optional supplier markup + energiebelasting) × 1.21. Tax rates live in `TAX` in `build.mjs` (source and check date included); add the next year when the Belastingdienst publishes it. The build warns when a year is missing. Explained on `/zo-rekenen-we/`.
- Brand assets (logo mark, wordmark, `icon.svg`, `favicon.png`, `apple-touch-icon.png`, manifest icons, `og.png`/`og.svg`) are rendered from code in `lib/brand.mjs` on every build (own PNG encoder on `node:zlib`, no deps). `static/` only holds files copied as-is (IndexNow key).
- Outputs: dashboard, SEO pages, `goedkoopste-uren.ics`, `feed.xml`, `prices.json`, sitemap.
- bol.com partner search links (affiliate, `rel="sponsored nofollow noopener"`) in a box on the dashboard and the guide pages, disclosed on `/privacy/`. No affiliates with energy suppliers; a placeholder (`#vergelijker`) is reserved for a future comparison widget.
- English version under `/en/` (for expats): the same data and components, rendered by `makeRender('en')` (euros per kWh with a decimal point, "market price excl. VAT", times labelled CET/CEST). The browser picks the language from `<html lang>`. NL↔EN page pairs are in `PAIRS` and `GUIDE_PAIRS` in `build.mjs`; every pair gets self canonicals, `hreflang` nl/en/x-default (x-default = Dutch), sitemap `xhtml:link` alternates and the NL/EN switcher in the header. No automatic redirects. English guides: `content/guides-en/*.md` → `/en/guides/<slug>/` (same pipeline as `content/gidsen`). `.ics` and `feed.xml` stay Dutch and are shared.
- "Last modified" dates (sitemap `<lastmod>`, JSON-LD `dateModified`, visible "updated" lines) are never the build date: price pages use the fetch time of the price data, guides their front matter `updated:` (else `date:`), and the FAQ, methodology, privacy, dynamic-vs-fixed and about pages use `STATIC_UPDATED` in `build.mjs`. Change that constant when you edit the text of those pages.
- GoatCounter click events: `bol-<name>` on bol.com partner links, `ics-download` on `.ics` links, `rss-feed` on feed links, `data-json` on `prices.json` links, `tool-<name>`/`footer-<name>` on links to the other CerberosTech tools, `vergelijker-disclosure`, `404-dashboard`/`404-dashboard-en` and `plan-ics` on the planner's calendar button. `write()` in `build.mjs` tags the links on every page, guide text included.
- About pages: `/over/` and `/en/about/` render `content/about/over.md` and `content/about/about.md` (markdown as-is), with AboutPage + BreadcrumbList JSON-LD and a footer link on every page.
- `node scripts/check-dist.mjs` checks a build in `dist/`: routes, canonicals, reciprocal hreflang, switcher, sitemap alternates, dates, structured data, click events, GoatCounter on every page, required files and internal links.
- `node scripts/indexnow.mjs --local` lists the URLs from `dist/sitemap.xml` (both languages) without sending anything.
